Sobre este proyecto

Esta página fue creada para practicar el flujo de trabajo con Git: commits, ramas, pull requests y resolución de conflictos.

Lo que aprendí

  • Crear y clonar repositorios
  • Trabajar con ramas (branches)
  • Resolver conflictos de merge
  • Documentar un proyecto con README
